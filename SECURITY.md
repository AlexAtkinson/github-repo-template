# Security Policy

This policy covers this repository's source, documentation, Git hooks, GitHub Actions, and release artifacts.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through GitHub's **Security** tab using **Report a vulnerability** (private vulnerability reporting / Security Advisories). Do not disclose vulnerability details in a public issue, discussion, or pull request.

Include the affected file, workflow, or release; the potential impact; and concise reproduction steps. Do not include real credentials or personal data in the report. If private reporting is unavailable, contact a repository maintainer privately using the contact information published in the repository. Do not post sensitive details publicly to request that contact information.

Maintainers will acknowledge and investigate reports as resources permit. No response or remediation deadline is guaranteed. Please allow time for triage and coordinated disclosure before publishing details.

## Supported Versions

This repository supports the current default branch. No older releases are designated as security-supported unless a release explicitly says otherwise.

## Repositories Created from This Template

Before publishing a repository created from this template, replace this policy with project-specific supported versions, reporting channels, and response expectations. Enable private vulnerability reporting in GitHub and provide a working private contact path.
